# Composition Patterns / 构图模式与原创规则

目标不是记住模板，而是给“抽象观点 → 小世界场景”一个稳定的起点。

## 1. Workflow 工坊流程

适合：输入 → 处理 → 输出、Agent、内容生产、自动化链路。

画法：左侧少量输入，中间一个处理动作，右侧少量输出。角色必须真正搬、塞、接、分拣或校准。

风险：最容易退化成“左乱 → 中机器 → 右整齐”。连续系列中最多使用一次这种完整结构。

## 2. Central Device 中央装置

适合：一个关键机制、模型能力、放大器、过滤器、压缩器。

画法：画面中央只有一个记忆点很强的大物件；角色围绕它操作。输入输出只保留最必要的 1–3 个元素。

不要每次都画齿轮机器，可以是调音台、烤箱、邮筒、显微镜、手摇装置、巨大抽屉、压花器等。

## 3. Repair Scene 修补现场

适合：断点、上下文丢失、协作卡住、错误恢复、系统脆弱点。

画法：把抽象问题变成一个“坏掉的东西”，例如漏水管、断桥、掉件轨道、松开的绳结。角色正在修，而不是举警告牌。

## 4. Sorting Table 分拣桌

适合：优先级、筛选、信息过载、内容分类、任务路由。

画法：俯视或斜俯视桌面，3–5 类容器或标签即可。让角色进行真实分拣，不要画正式矩阵表。

## 5. Handoff Path 接力路径

适合：多 Agent、多人协作、交付、阶段推进。

画法：一条弯曲路线、几个小站点或桌台；不同角色在递交同一个对象。重点是“东西怎么被传下去”。

## 6. Before / After 双世界对比

适合：手动 vs 自动、混乱 vs 稳定、错误做法 vs 正确做法。

画法：左右两个小世界，但不要镜像复制。两个世界应在空间结构、角色状态或物件关系上明显不同。

## 7. Calibration Bench 校准台

适合：判断力、质量控制、标准、反馈、对齐。

画法：小角色围绕秤、旋钮、音叉、标尺、样品台或调色盘进行调整。强调“判断在决定参数”，而不是普通检查清单。

## 8. Growth System 培育系统

适合：训练、长期主义、复利、能力成长。

画法：温室、育苗台、培养皿、修枝架等。重点是持续照料与环境条件，不要默认画一棵不断长高的树。

## 原创隐喻生成法

每张图先做四步，再写生图 prompt：

1. **提炼关系**：这句话真正表达的是筛选、放大、断裂、交付、回流，还是校准？
2. **选择动作**：搬、接、修、压、分、测、浇、排、递、回流。
3. **选择一个世界**：工坊、邮局、车站、温室、厨房、维修间、档案室、桌面剧场。
4. **确定角色职责**：Tiny Maker 必须直接推动变化发生。

优先：一个动作 + 一个主物件 + 一个角色职责。

## 构图变化规则

一组 5–8 张图至少变化 3 个维度：

- 镜头：全景 / 中景 / 近景 / 俯视；
- 方向：左→右 / 右→左 / 中央向外 / 环形 / 纵向；
- 场景：机器 / 桌面 / 路线 / 温室 / 维修现场；
- 角色数量：单人 / 双人接力 / 小组；
- 物理关系：流动 / 堵塞 / 修补 / 分类 / 校准 / 培育。

连续两张不要同构。

## 反复刻规则

参考图只用于校准：纸张、颗粒、粉彩色板、角色比例、可爱程度、信息密度和小世界氛围。

默认禁止机械复用：

- “MESSY IDEAS 箱子 → 蓝绿色机器 → 输送带输出”完整构图；
- 同一台青绿色创意机器；
- 同一只睡觉的猫；
- 同一摞书、同一组便签、同一排 PLAN / CREATE / SHARE 卡片；
- 同样的右上角手写注释布局；
- 每次都用灯泡、齿轮和星星代表创意。

如果主题还是“工作流”，可以改成：小邮局分拣、车站接力、修理间堵漏、厨房备料、档案室归档等完全不同的物理世界。

**统一的是视觉语言，不是场景模板。**
