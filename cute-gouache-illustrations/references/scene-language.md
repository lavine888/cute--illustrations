# Scene Language

## 核心方法：把观点变成“小世界里的真实动作”

不要从“可爱物件”开始想。先把观点拆成：

**谁 / 什么东西 → 在做什么 → 遇到什么阻力 → 发生什么变化。**

然后再把这个关系放进一个小世界。

---

## 1. 抽象关系 → 物理动作

| 抽象关系 | 可转成的动作 |
|---|---|
| 信息过载 | 分类、筛选、分箱、过滤 |
| 工作流 | 接力、输送带、车站、流水线 |
| 判断力 | 调音、挑种子、校准、配钥匙 |
| 模型放大能力 | 扩音、放大镜、浇水、增压 |
| Agent 协作 | 多个小站点接力、分工修理 |
| 上下文丢失 | 漏水、掉件、断桥、断线 |
| 反馈循环 | 回流管道、循环小火车、回信 |
| 迭代 | 打磨、试穿、修补、反复烘焙 |
| 优先级 | 排队、贴颜色标签、分层货架 |
| 复杂问题 | 拆箱、拆零件、分房间处理 |
| 不确定性 | 雾中路标、试探桥板、样品台 |
| 稳定输出 | 固定模具、校准仪、标准托盘 |

## 2. 五类高复用小世界

### A. 创意工坊

适合：AI、Agent、工作流、内容生产。

物件：机器、便签、齿轮、漏斗、工具袋、输送带、标签牌。

重点：不要每张都画同一台“创意机器”。机器结构必须随概念变化。

### B. 小邮局 / 分拣站

适合：信息流、任务分发、协作、路由、优先级。

物件：信封、邮袋、颜色标签、分拣格、推车、窗口。

### C. 小温室 / 花园

适合：成长、判断、长期主义、训练、复利。

物件：种子、浇水壶、盆栽、温室窗、支架、修枝剪。

不要把所有“成长”都画成植物；只在真正适合时用。

### D. 小车站 / 接力路线

适合：流程、多人协作、交付、阶段推进。

物件：轨道、小车、站牌、票、接力棒、桥。

### E. 桌面小剧场

适合：单个判断、两难、方法论、心理状态。

物件：秤、盒子、书、绳子、杯子、小桌、抽屉。

## 3. 角色动作库

角色应该在：

- 搬
- 推
- 拉
- 贴
- 接
- 剪
- 筛
- 浇
- 修
- 绑
- 称
- 装
- 分
- 递
- 拼
- 擦
- 调
- 开关
- 观察结果

避免：

- 站着指屏幕
- 站在角落微笑
- 举着灯泡
- 双手叉腰看成果
- 只作为比例尺存在

---

## 4. 小道具不是装饰

每一个关键道具都最好有语义：

- 纸箱 = 未整理输入
- 标签 = 分类 / 命名
- 漏斗 = 收敛
- 齿轮 = 转换机制
- 输送带 = 连续流程
- 轨道 = 固定路径
- 植物 = 生长 / 培养
- 绳结 = 依赖 / 卡点
- 水管 = 信息流 / 资源流
- 门 = 阶段门槛
- 桥 = 跨越断点

不要把这些符号当固定词典；同一个概念尽量尝试不同物理隐喻。

---

## 5. 让场景有一点幽默

这个风格的魅力来自“认真做事的小角色 + 略微荒诞的大任务”。

例如：

- 小角色拖着比自己大三倍的待办清单
- 两个角色努力堵住一根漏信息的水管
- 一个角色拿着超大标签机给混乱想法贴标签
- 一辆很小的任务车在复杂轨道上不断换站

幽默来自尺度和动作，不来自表情包。

---

## 6. 构图变化

连续系列可以轮换：

1. 全景：完整小世界
2. 中景：角色 + 大装置
3. 近景：手部 / 道具动作
4. 对比：左右两个小世界
5. 路线：斜向或 S 型路径
6. 俯视：桌面分拣 / 规划

避免 5 张连续都“左边输入、右边输出”。

---

## 7. 一个判断只画一个机制

如果一页同时出现：

- 机器
- 桥
- 火车
- 树
- 漏斗
- 三组角色

通常说明没有真正选出核心隐喻。

优先删到只剩一个主动作，再用少量生活化小物补气氛。
