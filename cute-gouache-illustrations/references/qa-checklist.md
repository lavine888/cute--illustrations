# QA Checklist

生成后至少过一遍以下检查。

## A. 风格

- [ ] 背景是暖奶油 / 暖白纸张，而不是纯白 UI 或真实摄影桌面
- [ ] 能看到水粉、蜡笔、彩铅的手作颗粒
- [ ] 没有明显塑料 3D 高光
- [ ] 色板以青绿、蜜桃、奶黄、珊瑚橙、薰衣草紫为主
- [ ] 颜色柔和，不是荧光糖果色
- [ ] 轮廓有轻微手绘不完美感

## B. 可爱程度

- [ ] 第一眼亲切、温暖
- [ ] 没有幼儿园贴纸素材感
- [ ] 没有日系大眼萌系角色感
- [ ] 星星、爱心、腮红等装饰有节制
- [ ] 角色表情简单，不靠夸张表情撑画面

## C. 概念表达

- [ ] 一张图只讲一个核心机制
- [ ] 主动作在 1–3 秒内能看懂
- [ ] 去掉文字后，画面仍有基本因果
- [ ] 没有用“灯泡 + 火箭 + 箭头”替代思考
- [ ] 物件承担语义，而不是纯装饰

## D. 角色

- [ ] 角色在真实执行动作
- [ ] 去掉角色后如果概念完全不受影响，需要重做角色位置
- [ ] 角色没有永远站在角落指东西
- [ ] 系列角色语言一致，但姿势和场景不机械重复
- [ ] 没有直接复刻参考图里的具体角色造型

## E. 构图

- [ ] 有明确主次
- [ ] 主体不超过画面约 70%–75%
- [ ] 有足够暖白留白
- [ ] 小物件没有淹没主动作
- [ ] 连续系列没有每张都“左乱右整”

## F. 文字

- [ ] 图内文字尽量少
- [ ] 中文没有明显错字
- [ ] 每个标签尽量控制在 2–8 字
- [ ] 没有长段正文
- [ ] 手写字像画面的一部分，而不是 UI 字体

## G. 系列一致性

- [ ] 纸张一致
- [ ] 色温一致
- [ ] 笔触与颗粒一致
- [ ] 角色比例一致
- [ ] 手写字重量一致
- [ ] 但每张场景、镜头和物件有变化

---

## 失败信号与优先修复

### 1. 看起来像 3D 玩具
优先修：材质、光影、景深。

### 2. 看起来像儿童绘本
优先修：减少表情、装饰和高饱和颜色，增加留白与编辑感。

### 3. 看起来像 PPT
优先修：删除面板、框线、标准箭头，把关系变成真实物理动作。

### 4. 可爱但看不懂
优先修：删道具，强化一个主动作；不要继续加标签解释。

### 5. 很好看但角色没用
优先修：让角色成为变化的直接执行者。

### 6. 中文错字多
优先修：减少文字；必要时生成无字版再后期排字。

---

## 20 分快速评分

每项 0–2 分：

1. 纸张与材质
2. 色板
3. 可爱但不幼稚
4. 核心隐喻
5. 角色动作
6. 构图留白
7. 文字克制
8. 原创场景
9. 系列一致性
10. 第一眼传播力

**16 分以下：不要直接交付。**

18–20：可直接作为公开示例。
