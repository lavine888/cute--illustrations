# Prompt Templates

## 1. 单张正文插图

```text
Create one editorial storybook explainer illustration for this idea:

[CORE IDEA]

Visualize it as one concrete physical action inside a tiny cozy world.
Do not use generic business icons.

Style:
- warm cream / off-white textured paper
- cute gouache + crayon + colored-pencil illustration
- visible dry-brush, waxy grain, handmade imperfect edges
- pastel teal, peach pink, butter yellow, coral orange, lavender accents
- rounded friendly handmade shapes
- one tiny maker character actively performing the core action
- low-tech workshop / tabletop world
- sparse handwritten labels only when necessary
- charming, warm, intelligent, slightly whimsical
- generous breathing room
- editorial explainer, not children's clipart

Composition:
[COMPOSITION]

Core physical metaphor:
[METAPHOR]

Character action:
[ACTION]

Objects:
[OBJECTS]

Optional short labels:
[LABELS]

Avoid:
- glossy 3D
- corporate vector illustration
- anime rendering
- tech dashboard
- PPT infographic
- photorealism
- excessive candy colors
- dense typography
- mascot standing idle
- copying any existing reference composition
```

## 2. 中文正文图模板

```text
把下面观点画成一张 4:3 中文正文插图：

“[核心判断]”

先把这句话翻译成一个具体物理动作，再放进一个温暖可爱的小世界。

视觉要求：
- 暖奶油色纸张，有轻微纸纤维
- 蜡笔 × 水粉 × 彩铅混合质感
- 能看到干刷、颗粒和不完全平滑的边缘
- 青绿色 + 蜜桃粉 + 奶油黄 + 珊瑚橙，少量薰衣草紫
- 圆润、亲切、聪明可爱，不幼稚
- 低科技手作场景
- 小角色必须真的执行核心动作
- 0–5 个中文短标签即可
- 保持足够留白

核心隐喻：[隐喻]
角色动作：[动作]
构图：[构图]
关键物件：[物件]
短标签：[标签]

不要：PPT 信息图、商业扁平插画、塑料 3D、动漫厚涂、赛博 UI、大段文字、只站着卖萌的吉祥物。
```

## 3. 系列图模板

```text
Create a coherent series of [N] cute gouache explainer illustrations.

All images must share:
- the same warm cream paper world
- the same gouache/crayon texture
- a stable pastel palette
- the same character language
- similar handwritten label style
- similar visual density

But every image must invent a different scene and physical metaphor.
Do not reuse the same machine, conveyor belt, left-to-right layout, or mascot pose.

Image 1: [idea + metaphor + action]
Image 2: [idea + metaphor + action]
Image 3: [idea + metaphor + action]
...

Generate each image separately.
```

## 4. 小红书 3:4 轮播

```text
Use a 3:4 vertical canvas.
Keep the upper area relatively quiet for one short handwritten Chinese title.
Use the middle and lower area for one complete cute physical metaphor scene.

Title: [TITLE]
Short explanation: [OPTIONAL 1-3 SHORT LINES]
Scene: [SCENE]
Character action: [ACTION]
Labels: [0-4 SHORT LABELS]

The image should feel like a handmade gouache storybook page for adults, not a children's poster.
```

## 5. 无字版本

当中文生成不稳定时：

```text
Generate the illustration with no text at all.
Leave intentional blank areas for later typography.
Use physical objects, character action, arrows or simple visual grouping to make the logic readable without words.
```

## 6. 编辑配方

### 太 3D

```text
Keep the exact composition and concept, but repaint the entire image as flat handmade gouache and crayon on textured cream paper. Remove glossy surfaces, plastic highlights, realistic depth of field, and CGI lighting. Preserve dry-brush texture and imperfect hand-drawn edges.
```

### 太幼稚

```text
Keep the warmth and cute proportions, but make the illustration more editorial and restrained: fewer decorative stars/hearts, calmer expressions, more negative space, muted pastel colors, and clearer visual hierarchy. Avoid children's clipart energy.
```

### 太 PPT

```text
Remove boxes, formal arrows, diagram labels, UI panels and infographic structure. Re-express the same logic as one physical scene where characters and objects perform the process naturally.
```

### 太乱

```text
Preserve the core metaphor and main character action, but remove at least 30% of secondary props. Keep one dominant action, one main object group, and more quiet cream-paper space.
```

### 吉祥物太装饰

```text
Recompose so the mascot physically causes the key transformation. It must pull, carry, connect, sort, repair, feed, label, pour, calibrate or hand off something essential to the concept.
```
