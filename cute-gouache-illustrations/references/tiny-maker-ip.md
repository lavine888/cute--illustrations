# Tiny Maker / 小芽创客 IP

## 角色定义

Tiny Maker（小芽创客）是 Cute Gouache Illustrations 的默认弱重复视觉角色。

它不是必须每张出现的固定吉祥物，也不是为了“加一点可爱”才放进画面。只要出现，就应该承担核心动作：搬运、修补、分拣、校准、连接、浇灌、推动、贴标签、装配或交付。

一句话：**像一个住在创意工作坊里的认真小工匠。**

## 外形语言

保持“同一物种感”，不要锁死为某个具体动物：

- 奶油白 / 暖米色的圆润身体；
- 头略大、四肢短，但不要婴幼儿比例；
- 黑色点眼或短弯眼，嘴极简；
- 轻微腮红即可，不要大眼高光；
- 轮廓柔软、略不规则，像水粉和蜡笔画出来；
- 默认有 1 个识别元素：小叶芽 / 围裙 / 工具袋 / 小帽子，最多选 2 个；
- 服装保持朴素，不要复杂 cosplay。

不要直接复刻参考图里的兔耳、猫耳、服装、帽子或机器组合。

## 性格

- 认真做事，而不是表演可爱；
- 有一点笨拙和尺度反差，但不蠢；
- 温暖、好奇、愿意动手；
- 遇到麻烦时会修、搬、试，而不是夸张惊讶；
- 幽默来自“一个很小的角色在处理一个很大的问题”。

## 动作库

优先动作：

- 搬、推、拉、接、递、塞、取；
- 贴标签、分箱、筛选、称重；
- 缝、补、拧、剪、绑、接线；
- 调旋钮、校准、测量、观察结果；
- 浇水、修枝、播种、移栽；
- 开门、过桥、扶梯、搭台；
- 装箱、盖章、排队、交付。

动作必须服务观点，不要随机摆 pose。

## 多角色规则

需要表达协作时可以出现 2–4 个 Tiny Maker：

- 外形属于同一世界，但可用帽子、围巾、工具或体型做轻微区分；
- 每个角色负责不同动作，不要一群角色同时举手欢呼；
- 多角色最好形成接力、分工、堵漏、搭桥、递交等关系；
- 角色数量一多，就减少背景装饰和文字。

## 禁止

- 不要做成 Sanrio-like、已有知名 IP 或动漫角色模仿；
- 不要大眼、闪亮瞳孔、夸张哭笑；
- 不要每张都塞一只猫或兔子；
- 不要给角色加复杂服装和配饰；
- 不要让角色站在角落指着流程图；
- 不要把角色当 logo 贴纸贴在画面里；
- 不要让角色比核心机制更抢戏。

## 判断标准

问三件事：

1. **角色在改变什么？** 如果答不出来，它只是装饰。
2. **动作是否能替代一部分文字解释？** 如果不能，动作太弱。
3. **去掉角色后，核心隐喻是否完全不受影响？** 如果是，重新设计角色职责。

角色的价值不是“萌”，而是让抽象关系真正发生。
