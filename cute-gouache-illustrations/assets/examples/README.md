# Visual Calibration Examples

这个目录用于存放少量风格基准图，作用是校准：

- 暖奶油纸张与纸纤维；
- 水粉 × 蜡笔 × 彩铅的颗粒和边缘；
- 粉彩青绿 / 蜜桃 / 奶黄 / 珊瑚橙的色温；
- Tiny Maker 的比例与可爱程度；
- 小世界场景的信息密度与留白；
- 手写批注的克制程度。

这些图片只应**低频读取**。默认生成时先依赖 `references/` 里的文字规则，不要把示例图当成构图模板。

新增 benchmark 图时，优先覆盖不同结构：修补现场、分拣桌、接力路径、校准台、双世界对比、培育系统等，而不是连续添加“输入 → 机器 → 输出”的同构案例。
