# Notice

This repository defines a reusable illustration workflow and visual grammar for AI-assisted image generation.

The visual system is based on general design attributes such as:

- warm cream paper backgrounds
- gouache, crayon, and colored-pencil textures
- soft pastel palettes
- rounded friendly characters
- low-tech miniature-world scenes
- sparse handwritten labels
- physical visual metaphors

Reference images are used only to calibrate broad visual attributes such as texture, palette, composition density, and narrative tone.

When generating new work, do not mechanically reproduce a reference image's exact character, text, composition, machine, prop arrangement, or other distinctive scene details. Re-invent the metaphor and scene for the current content.

In short: **borrow the visual grammar, not the exact picture.**
