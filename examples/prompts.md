# Prompt Examples

## 1. AI / Agent 文章正文图

```text
Use $cute-gouache-illustrations 为下面这篇文章生成 5 张 4:3 正文配图。

要求：
- 每张图先提炼一个认知锚点；
- 再把它变成一个真实物理动作；
- 场景是温暖可爱的低科技小世界；
- 蜡笔 × 水粉质感；
- 角色必须参与核心动作；
- 图内中文控制在 0–5 个短标签；
- 不要 PPT、不要塑料 3D、不要商业扁平插画。

<文章>
```

## 2. 小红书 7 页轮播

```text
Use $cute-gouache-illustrations 把下面内容做成 7 页 3:4 小红书轮播。

先输出 shot list，再生成图片。
整组保持同一纸张、色板、角色语言和手写感，但每一页必须换场景、换动作、换构图。

第 1 页要有封面感；第 3–5 页承担最核心的认知转折；最后一页给一个行动或总结。

<内容>
```

## 3. 单个观点

```text
Use $cute-gouache-illustrations 为这句话生成一张图：

“真正稀缺的不是工具，而是判断。”

不要画奖杯、灯泡、金钱符号或天平。
先发明一个低科技、可爱、成立的物理隐喻，再生成。
```

## 4. 工作流概念

```text
Use $cute-gouache-illustrations 解释：

“Agent 不是一个更聪明的聊天框，而是一条能持续推进任务的工作链。”

请用一个小型车站 / 接力路线 / 分拣站的物理场景表达。
不要画聊天 UI。
```

## 5. 判断放大器

```text
Use $cute-gouache-illustrations 画：

“AI 会放大你的判断，不会替你拥有判断。”

不要画机器人和大脑。
可以考虑调音台、扩音装置、种子培育、校准器等物理关系，但需要重新设计一个原创场景。
```

## 6. 只做 shot list

```text
Use $cute-gouache-illustrations 先不要生成图片。

请从下面文章里挑 6 个最值得画的认知锚点。
每个输出：
- 核心判断
- 小世界场景
- 物理动作
- 角色动作
- 关键道具
- 0–5 个短标签
- 构图类型

<文章>
```

## 7. 无字版

```text
Use $cute-gouache-illustrations 生成无字版本。
所有中文留到后期添加。
画面必须依靠角色动作、物件关系和空间结构把逻辑讲明白，并为后期文字留出安静区域。
```

## 8. 修掉 3D 感

```text
Use $cute-gouache-illustrations 编辑这张图。
构图和核心概念不变，把材质从塑料 3D 改成奶油纸上的水粉 + 蜡笔手绘：去掉镜面高光、真实景深和 CGI 光照，增加干刷、颗粒、露纸和不规则边缘。
```

## 9. 降低幼稚感

```text
Use $cute-gouache-illustrations 编辑这张图。
保留可爱和温暖，但降低“儿童绘本”感：减少星星爱心、收敛表情、降低饱和度、增加留白、让核心动作更清楚。
```
